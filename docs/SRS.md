## 1. 引言

### 1.1 目的

本 SRS 供开发、测试与验收使用，规定 PetPal 的功能行为、接口逻辑、验收标准、边界与异常处理，以及与全局工程约束（`.cursor/rules/`）一致的指标。

### 1.2 定义


| 术语   | 含义                   |
| ---- | -------------------- |
| 宠物窗口 | 展示角色与动画的置顶悬浮窗        |
| 皮肤包  | 符合约定目录结构与元数据的资源集合    |
| 提醒   | 用户创建的本地定时事件，触发 UI 提示 |
| 记忆条目 | 一条可追溯的记录，含时间戳、类型（互动事件/用户备忘等）、正文或结构化字段；仅存于本机 |
| 精简记忆 | 在保留语义前提下减少冗余与篇幅：合并、折叠、截断或生成短摘要（默认规则驱动、本地执行） |
| 提纯记忆 | 强化重要信息、弱化噪声：标星、评分排序、归档或隐藏低价值条目；可组合为预设方案 |


### 1.3 参考

- `docs/PRD.md`
- 仓库规则：`petpal-tech-stack.mdc`、`petpal-performance.mdc`、`petpal-compliance.mdc`、`petpal-testing.mdc`

## 2. 详细功能需求

### FR-01 桌面悬浮窗（P0）


| 项   | 说明                                             |
| --- | ---------------------------------------------- |
| 描述  | 提供独立悬浮窗口展示宠物，不占用任务栏主工作区为必选（平台差异允许最小化任务栏图标）。    |
| 输入  | 启动应用；用户拖动；用户切换「始终置顶」设置（P1）。                    |
| 输出  | 可见宠物渲染区域；窗口位置持久化（P1 或 P0 最小实现：会话内记忆）。          |
| 主流程 | 启动 → 创建透明/分层窗口 → 加载默认皮肤 → 进入 idle 动画循环（低功耗实现）。 |
| 约束  | 默认不抢键盘焦点；点击宠物可响应但不强制切焦点（平台允许范围内）。              |


### FR-02 鼠标交互（P0）


| 项   | 说明                                              |
| --- | ----------------------------------------------- |
| 描述  | 鼠标悬停、点击触发不同动画或音效。                               |
| 输入  | 指针进入/离开区域；主键按下/释放（或双击，二者择一作为标准并在验收中固定）。         |
| 输出  | 状态切换至 `hover` / `interact`；可选短音效。               |
| 主流程 | 事件捕获 → 防抖（如 150ms 内合并重复进入）→ 播放对应动画片段 → 回到 idle。 |


### FR-03 动作动画（P0）


| 项   | 说明                                                 |
| --- | -------------------------------------------------- |
| 描述  | 至少 idle 与 interact 两套动画；使用精灵表或序列帧；循环与一次性片段可配置。     |
| 输入  | 时间轴 tick（建议 `requestAnimationFrame` + 可见性 API 降频）。 |
| 输出  | 帧索引更新；GPU/CPU 占用可控。                                |
| 主流程 | 状态机驱动当前 `AnimationClip` → 渲染当前帧 → 结束条件满足则回 idle。   |


### FR-04 自定义皮肤（P1）


| 项             | 说明                                                                         |
| ------------- | -------------------------------------------------------------------------- |
| 描述            | 用户选择官方皮肤或导入皮肤包后切换显示资源。                                                     |
| 输入            | 皮肤包目录或压缩包（实现二选一，在实现说明中固定）；`manifest.json`（示例字段见下）。                         |
| 输出            | 成功则替换精灵与元数据；失败则保持上一套皮肤并提示原因。                                               |
| manifest 示例字段 | `id`、`name`、`version`、`author`、`frames`（路径与布局）、`anchor`（可选）、`hitArea`（可选）。 |


### FR-05 日程提醒（P1）


| 项   | 说明                                                         |
| --- | ---------------------------------------------------------- |
| 描述  | 用户创建提醒项，到达触发时间在应用内展示通知；数据仅存本地。                             |
| 输入  | 日期时间（本地时区）、标题文本、可选备注；可选「仅一次」。                              |
| 输出  | 到时弹层或系统通知（若启用且平台允许）；用户标记完成/关闭。                             |
| 主流程 | 保存至本地存储（SQLite/JSON 等，实现定稿）→ 注册计时器或系统计划 → 触发 → 展示 → 记录已消费。 |
| 约束  | **不得**向网络发送提醒内容；无账号体系。                                     |


### FR-06 跨平台安装包与构建（P0/P1）


| 项   | 说明                                      |
| --- | --------------------------------------- |
| 描述  | CI 或发布脚本在 Windows、macOS、Linux 上产出可安装工件。 |
| 输入  | 版本号、签名证书（各平台按运维配置）。                     |
| 输出  | 各平台安装包 + 校验和文件（推荐）。                     |


### FR-07 互动记忆库（P1）


| 项      | 说明                                                                 |
| ------ | ------------------------------------------------------------------ |
| 描述     | 持久化记录用户与宠物的互动及可选备忘，形成可浏览的时间线；**数据不出本机**。                              |
| 输入     | 系统自动记录：互动类型、时间（本地时区）；用户可选：短文本备忘、标星。                                  |
| 输出     | 列表/时间线 UI；支持按类型、日期、关键词（若实现）筛选；支持单条删除与批量选择。                            |
| 主流程    | 事件产生 → 写入本地存储（与 FR-05 隔离命名空间）→ 列表增量刷新。                               |
| 约束     | **禁止**网络上传；导出（若提供）仅为用户显式触发的本地文件写入。                                    |
| 存储上限   | 产品配置默认上限（如总条数或总字节）；触达时提示用户执行精简或手动删除。                                  |


### FR-08 精简记忆（P1）


| 项    | 说明                                                                 |
| ---- | ------------------------------------------------------------------ |
| 描述   | 类「人类遗忘细节但保留梗概」：降低冗余与体积，使列表可读、占用可控。                                    |
| 输入   | 用户触发「执行精简」；可选策略参数：时间窗口（如仅处理 30 天前）、合并规则（同日同类事件合成一条）、摘要长度上限。           |
| 输出   | 原详细条目被替换或归档为「摘要条目」（实现二选一，需在技术说明中固定）；展示精简报告（合并条数、释放空间）。                 |
| 主流程  | 预览（可选）→ 用户确认 → 事务性写入 → 刷新 UI。                                          |
| 约束   | 默认实现为**本地确定性算法**；不调用外网 API。若未来增加可选本地模型，须默认关闭且明示资源占用。                     |


### FR-09 提纯记忆（P1）


| 项    | 说明                                                                 |
| ---- | ------------------------------------------------------------------ |
| 描述   | 类「人类突出重要回忆」：提升高价值条目的可见性，压低噪声。                                          |
| 输入   | 用户标星/取消标星；用户选择提纯预设（如「保留标星与近 7 日」「仅保留高分条」）；评分规则至少含**近因**与**频次**（可加权，默认权重文档化）。 |
| 输出   | 排序变化，归档区与主时间线分离或折叠展示；可导出提纯后的快照（本地文件，可选）。                               |
| 主流程  | 调整标星或运行预设 → 重算分数/分区 → UI 更新。                                            |
| 约束   | 评分逻辑可解释、可单测；**不得**依赖云端用户画像。                                              |

## 3. 验收标准（可量化、可测试）

### 3.1 功能验收


| 需求 ID | 验收标准                                                          |
| ----- | ------------------------------------------------------------- |
| FR-01 | 在三类目标系统各至少一台设备上：应用启动后 5s 内可见宠物；窗口可拖动；关闭后进程退出（无僵尸进程，以各平台工具验证）。 |
| FR-02 | 悬停与点击各至少 10 次连续操作无崩溃；动画与状态一致；无未处理异常日志（约定日志级别）。                |
| FR-03 | idle/interact 切换可见；后台切换至其他应用后，宠物动画 tick 符合降频策略（见性能）。          |
| FR-04 | 导入合法皮肤包后 3s 内完成切换；非法包失败且不损坏当前皮肤；有用户可见错误文案。                    |
| FR-05 | 设置 2 分钟后触发的测试提醒，误差在 ±10s（排除系统休眠）；休眠唤醒后行为在 SRS「边界」中说明。         |
| FR-06 | 每平台有一份安装包成功安装并启动的录屏或检查清单归档。                                   |
| FR-07 | 连续产生 ≥5 条记忆后重启应用，记录仍存在；断网环境下功能一致；网络抓包无记忆相关出站流量。                    |
| FR-08 | 执行精简前后条数/字节数减少可度量；合并结果与策略一致（抽样 10 条对照）；若支持撤销则验证一次，否则 UI 明示不可撤销。      |
| FR-09 | 标星条目在默认排序中高于未标星（同分按时间）；至少两种提纯预设可用且结果可重复。                            |


### 3.2 性能验收（与 `petpal-performance.mdc` 对齐）


| 指标     | 条件               | 阈值     | 测量方法（可复现）                  |
| ------ | ---------------- | ------ | -------------------------- |
| 常驻内存   | 启动后静置 5min，无用户操作 | < 50MB | 各平台任务管理器或 `ps` 采样至少 3 次取平均 |
| 空闲 CPU | 同上               | < 1%   | 1min 窗口内平均 CPU 占用          |


### 3.3 安全与合规验收


| 项   | 标准                                              |
| --- | ----------------------------------------------- |
| 隐私  | 抓包或本地防火墙验证：默认配置下无未文档化的外联请求；**记忆与摘要**不产生外联                  |
| 权限  | `tauri.conf` / capabilities 与 PRD「权限列表」一致，无多余权限 |
| 许可证 | 根目录 `LICENSE` 为 MIT；第三方 NOTICES 完整              |


### 3.4 测试与覆盖率


| 项       | 标准                                 |
| ------- | ---------------------------------- |
| 单元测试覆盖率 | ≥ 90%（与 `petpal-testing.mdc` 一致）   |
| TDD     | 新增逻辑先有失败测试再实现（通过 MR 抽检与 checklist） |

## 4. 边界条件与异常处理


| 场景               | 预期行为                                                     |
| ---------------- | -------------------------------------------------------- |
| 显示器配置变更（插拔、缩放变更） | 宠物窗口位置钳制在可见区域内；若越界则回退到默认角落                               |
| 系统休眠/唤醒          | 唤醒后重新校准下一提醒时间；错过的提醒策略：合并为一条「你有 N 个过期提醒」或丢弃（产品二选一，默认合并提示） |
| 皮肤包缺失资源文件        | 拒绝加载并提示缺失路径；保留上一套皮肤                                      |
| 磁盘满（本地存储失败）      | 提醒创建失败并提示；不崩溃                                            |
| 用户拒绝通知权限         | 应用内气泡仍可显示（若窗口可见）；设置中说明权限                                 |
| 极 rapid 点击       | 防抖/动画队列不堆积爆内存；最长队列长度有上限                                  |
| 记忆存储达上限         | 阻止写入新条目前提示；引导用户精简/删除；不静默丢数据                                  |
| 精简过程中断（崩溃）      | 下次启动要么回到精简前一致状态，要么完成精简（依赖事务）；不得出现半条损坏记录                        |
| 用户误删重要记忆        | 若提供回收站则保留恢复期；若不提供则删除前强确认                                       |

## 6. 里程碑计划（3 个节点）


| 里程碑            | 目标内容                                         | 退出准则（摘要）                                       |
| -------------- | -------------------------------------------- | ---------------------------------------------- |
| **M1 — Alpha** | 悬浮窗 + 基础交互 + idle/interact 动画；Windows 首发构建成功 | FR-01～FR-03 在 Win10+ 上通过 §3.1 用例；性能初测达标或已登记偏差项 |
