# PetPal 产品需求文档（PRD）


| 属性         | 内容                                                           |
| ---------- | ------------------------------------------------------------ |
| 产品名称       | PetPal                                                       |
| 形态         | 跨平台轻量桌面宠物应用                                                  |
| 技术方向（工程约束） | Tauri 2 + Svelte 5 + TypeScript + Rust（见仓库 `.cursor/rules/`） |
| 文档版本       | v0.2                                                         |
| 状态         | 草案，待产品确认                                                     |


---

## 1. 项目背景与目标

### 1.1 背景

用户在长时间使用电脑时，需要低干扰、情绪友好的桌面陪伴；同时希望有轻量提醒能力，而不引入重型协作工具或复杂账号体系。

### 1.2 产品目标

- **核心目标**：提供一款**跨平台**、**资源占用可控**的桌面宠物，支持悬浮展示、基础互动、动画表现、外观自定义、**本地互动记忆（含精简与提纯）**与本地日程提醒。
- **商业/合规目标**：以 **MIT** 开源发布；**不采集、不上传用户行为与内容数据**；权限按需最小化。
- **交付目标**：在约定操作系统上提供**可安装产物**，并交付**源码**与**用户/开发文档**。

### 1.3 成功指标（方向性）


| 维度  | 指标                                                                     |
| --- | ---------------------------------------------------------------------- |
| 性能  | 空闲常驻内存、空闲 CPU 满足工程基线（见「非功能需求」与 `.cursor/rules/petpal-performance.mdc`） |
| 质量  | 单元测试覆盖率与 TDD 流程符合工程基线（见 `.cursor/rules/petpal-testing.mdc`）            |
| 覆盖  | Windows 10+、macOS 12+、Ubuntu 22.04+ 均有可验证安装包或通过文档说明的构建路径               |

## 2. 用户画像与使用场景

### 2.1 用户画像


| 画像         | 描述              | 诉求            |
| ---------- | --------------- | ------------- |
| A：办公族      | 长时间桌面办公，希望低干扰陪伴 | 可忽略、不占焦点、不占资源 |
| B：学生/创作者   | 需要温和提醒与情绪调节     | 日程提醒、轻互动解压    |
| C：开源用户/贡献者 | 关注隐私与可定制        | MIT、可换肤、可审计代码 |


### 2.2 使用场景（摘要）

1. **开机或手动启动**：宠物出现在桌面顶层区域，不抢占当前工作窗口焦点（可配置）。
2. **工作间隙**：鼠标移入宠物区域触发简单反馈（注视、招手等）。
3. **个性化**：用户更换皮肤包或主题参数，使外观符合个人偏好。
4. **日程**：用户设置本地提醒（时间 + 文案/可选音效），到时在桌面内展示提醒；**数据仅存本机**。
5. **记忆**：宠物将关键互动与可选简短备忘记入**本地记忆库**；用户可像整理自己的回忆一样，对记忆做**精简**（折叠细节、合并同类、控制篇幅）与**提纯**（标星/加权保留重要片段、淡化低价值条目），全程**不上传**。

## 3. 功能清单（按优先级）

### P0（首发必须）


| ID      | 功能        | 说明                                                          |
| ------- | --------- | ----------------------------------------------------------- |
| F-P0-01 | 桌面悬浮窗     | 无边框或极简边框；始终置顶可配置；可拖动位置；多显示器场景下在所在屏幕内可定位                     |
| F-P0-02 | 基础鼠标交互    | 至少：悬停、点击（或双击）触发不同反馈；需防抖与可访问性考量（不要求读屏全覆盖，但交互目标需足够大）          |
| F-P0-03 | 动作动画      | 至少 2 套状态机动画（idle / interact）；帧率与资源占用可控                      |
| F-P0-04 | 应用生命周期    | 正常退出、崩溃后重启可恢复默认位置或安全默认（见 SRS 边界）                            |
| F-P0-05 | 跨平台构建与安装包 | Windows / macOS / Linux（Ubuntu 22.04+ 代表）产出可安装格式（具体格式见 SRS） |


### P1（首发后短期）


| ID      | 功能    | 说明                                        |
| ------- | ----- | ----------------------------------------- |
| F-P1-01 | 自定义皮肤 | 支持官方皮肤包格式 + 用户导入；至少包含精灵图或序列帧 + 元数据（见 SRS） |
| F-P1-02 | 日程提醒  | 本地创建/编辑/删除提醒；到时通知；**无网络同步**               |
| F-P1-03 | 设置面板  | 音量、置顶、开机自启（若平台允许且用户授权）、宠物位置记忆             |
| F-P1-04 | 互动记忆库 | 将互动事件与用户备忘以时间线形式**仅存本机**持久化；可检索、删除、导出为本地文件（可选） |
| F-P1-05 | 精简记忆   | 按策略压缩记忆占用：合并重复/近似项、按日/周折叠为短摘要、限制保留条数或总字数（规则可配置，**默认不依赖外网模型**） |
| F-P1-06 | 提纯记忆   | 突出「重要」记忆：标星、重要性评分（如近因+频次）、低价值条目归档或淡化展示；支持一键执行预设提纯方案 |


### P2（中长期）


| ID      | 功能        | 说明                                  |
| ------- | --------- | ----------------------------------- |
| F-P2-01 | 扩展动画与情绪状态 | 多情绪、随机 idle 组合                      |
| F-P2-02 | 皮肤工坊/分享说明 | 仅文档化皮肤包制作规范；**不包含**云端皮肤商店（避免默认出站依赖） |
| F-P2-03 | 国际化       | 中英 UI 文案（按资源投入取舍）                   |

## 4. 非功能需求

### 4.1 性能（与仓库规则一致）

- 典型**空闲**场景：**常驻内存 < 50MB**；**空闲 CPU < 1%**（测量口径见 SRS）。
- 动画与渲染避免常驻高帧率空转；后台时降低 tick 频率。

### 4.2 兼容性


| 平台      | 最低版本                                               |
| ------- | -------------------------------------------------- |
| Windows | 10 及以上（64 位为主）                                     |
| macOS   | 12 及以上（架构：Intel + Apple Silicon 均需有构建策略）           |
| Linux   | Ubuntu 22.04+（代表 GTK/WebKit 运行环境；其它发行版尽力兼容，在文档中声明） |


### 4.3 安全与隐私（与仓库规则一致）

- **许可证**：MIT；依赖合规可查。
- **数据**：用户日程、**记忆库**与皮肤等配置**仅存本地**；记忆与摘要**不得**上传云端；**禁止**未说明的遥测、用户数据上传与第三方分析 SDK（除非用户明确安装的独立插件且另行声明，本产品首版不包含）。若未来提供可选「本地模型」辅助摘要，须在隐私说明中明示且默认关闭。
- **权限**：仅申请实现功能所必需的系统能力（通知、自启、文件选取等），并在隐私说明中列出。

### 4.4 可维护性与质量

- 严格 TDD 流程；**单元测试覆盖率 ≥ 90%**（与 `.cursor/rules/petpal-testing.mdc` 一致）。

## 5. 界面原型描述（文字）

### 5.1 主窗口（宠物层）

- **整体**：透明或半透明背景区域承载宠物精灵；边缘无传统标题栏，或仅保留极简拖动条/系统菜单入口。
- **宠物区域**：居中或略偏下；点击热区与视觉一致。
- **反馈**：悬停时宠物短暂动画；点击触发第二套动画或音效（可关）。

### 5.2 设置 / 日程 / 记忆（可同窗口或独立子窗口）

- **设置**：开关型（置顶、开机启动、音量）、皮肤选择、关于与开源许可。
- **日程**：列表 + 新建；字段至少时间、标题、可选重复规则（首版可简化为单次）。
- **记忆**：时间线或列表视图；单条含时间、类型（互动/备忘）、摘要正文；提供「精简」「提纯」入口与策略说明；危险操作（清空、批量删除）需二次确认。

### 5.3 提醒弹层

- 弱打断：小卡片或宠物气泡，带「知道了」与「稍后（可选）」；不强制全屏。

## 7. 假设与待确认事项

以下已在文中做默认假设，**若与产品预期不符请评审修订**：

1. **日程与提醒**：仅本地存储，无账号、无云同步。
2. **皮肤格式**：首版采用「包目录 + 元数据清单」方式，具体字段以 SRS 为准。
3. **开机自启**：依赖各平台允许的最小 API；若某平台审核限制强，可降级为「文档说明手动添加」。
4. **全局约束来源**：以 `.cursor/rules/petpal-*.mdc` 为工程强制基线，PRD/SRS 与之冲突时以**先澄清再改规则**为原则。
5. **记忆与智能**：「精简」「提纯」首版以**可解释的规则与本地算法**实现；若引入可选本地 LLM，须独立评审且不违背「无默认外联」与性能基线。
